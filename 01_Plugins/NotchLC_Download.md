# NotchLC plugin for Adobe

Download the free NotchLC plugin for Adobe Creative Cloud (After Effects, Premiere Pro and Media Encoder) from the official site:

**[notchlc.notch.one](https://notchlc.notch.one/)**

- Windows 8 or higher, and macOS 13 (Ventura) or higher.
- Free. No Notch Builder or Playback license needed.
- Install your Adobe apps first, then run the plugin installer.
- If After Effects is open while you install, restart it so the plugin loads.
