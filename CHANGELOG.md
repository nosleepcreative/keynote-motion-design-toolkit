# Changelog

All notable changes to the toolkit are listed here, newest first. Add a line whenever a preset, Quick Action or guide changes, so the team knows what is current.

## 0.1.0 (Unreleased)

First public version.

### Added
- README with terminology, a codec guide (quick answer for what to render, and settings and limits for ProRes 422 HQ, ProRes 4444, NotchLC and HEVC 4K) and how-to guides.
- `01_Plugins`: link to download the free NotchLC plugin for Adobe.
- `02_AfterEffects/01_AEP`: `Keynote_Template_v01.aep` project template, which you can replace with your team's own.
- `02_AfterEffects/02_RenderPresets`: output module presets (`.aom`) for ProRes and NotchLC.
- `03_macOS/QuickActions`: Quick Actions to convert to HEVC 4k, with and without alpha.
- `docs`: how-to GIFs and the Output Module Settings reference image.
